# AI assistants

The repository has two separate assistants:

- [Care Assistant](../ai/care-assistant.md): persistent conversations,
  Gemini intent routing, and deterministic care-workflow actions.
- [RAG assistant](../ai/rag-system.md): authenticated questions over indexed
  daily logs and text submitted through the RAG ingestion API.

Do not merge their data flows or describe either assistant as a diagnostic
service.
